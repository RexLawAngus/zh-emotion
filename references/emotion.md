# 情绪判断与强度约定

## 标签与相关维度

可用喜悦、悲伤、愤怒、恐惧／焦虑、厌恶、惊讶、羞耻、内疚、失望、无奈、宽慰、感激、思念等词。按文本选词，可多标签；词表不封闭，不只取负面情绪。

态度（认同、反对）、调节方式（克制、回避）、交流意图（求助、安慰、结束讨论）及关系描述分别记录，不当作情绪强度。项目有既定标签时按其编码手册使用；没有手册就保留自然语言，不宣称分类已验证。

## 证据与支持程度

| 来源 | 可支持的结论 | 限度 |
|---|---|---|
| “我很失望” | 主体报告失望 | 不等于独立验证内部状态或病程 |
| “她因失约而失望” | 文本描述她失望，指向失约 | 保留叙述层级和来源 |
| 语言／行为线索 | 当前语境下可能表达某种情绪 | 标点、动作、句式有其他解释 |
| 听者／读者反馈 | 反馈者报告的体验或理解 | 不能推广到所有受众 |

重要判断标记支持程度：

- **明确**：原文明示该情绪、主体及必要关系，仍保留“自述／描写”的性质。
- **有依据**：语境支持推断，仍存在其他解释。
- **待定**：关键语境缺失，或多种解释难以区分。

这些是分析标记，不是统计概率。“明确自述”不等于真实体验已经验证。重复同一事实不算多个独立证据。

## 否定、引用与时间

- 核对否定范围：“我不难过”与“我不是不难过”不同。“没有不开心”也不能直接等同强烈喜悦。
- 区分“当时难过／现在释然”“如果失败会难过／已经失败而难过”。
- 引用、转发、歌词、演戏、角色独白保留来源。输入者不自动成为感受者。
- 用户纠正自身感受时记录新自述及前后关系，不把否认本身当作掩饰证据。
- 对“累死了”“不想活了”等表达结合字面、惯用夸张、主体和时态判断。当前真实安全线索交调用方处理；引用或文学语境不能单独排除现实风险。

## 反讽与间接表达

先列字面意义，再核对事件结果、惯用表达、话轮、明确语气／动作和后续澄清。褒义与负面结果的落差可支持反讽假设，不能单独证明愤怒、悲伤或敌意。

“你真行”“随便”“呵呵”“没事”“好吧”有多种用途。单句保留歧义，已知语境缩小解释范围。识别反讽后仍要判断主体和对象。

克制与掩饰需要依据；不能仅因表达平静就推断强烈情绪，不能仅因没谈感受就认定回避。

## 强度：按需分别报告

以下是供讨论和试验使用的序数约定，未经心理测量验证，不是临床严重度。不同情绪、语境和个体的分数不能当作等距量比较，不默认求平均或总分。

### 文本表达强度 expression_intensity

对每种情绪分别编码，综合语义、语气和叙述方式。

| 值 | 约定 | 自拟参照 |
|---|---|---|
| 0 | 本单元未出现明确的目标情绪表达，不代表主体内心无情绪 | “会议改到三点。” |
| 1 | 弱化或轻微表达 | “有一点失望。” |
| 2 | 清楚表达，未着重强调程度 | “我很失望。”中的“很”可为常规搭配 |
| 3 | 明确强化程度 | “这件事让我非常失望。” |
| 4 | 显著强化并扩展表达 | “我失望透了，连解释都听不下去。” |
| 5 | 表达达到文本所述极端程度 | “我失望到极点，已经无法承受再一次落空。” |
| null | 歧义未消解、无法确定或未请求编码 | 单独的“行，你开心就好。” |

参照不用于关键词机械匹配。“很”的作用须结合用法；标点、动作、身体反应、字数都不足以独立决定等级。给分时指出语义依据，相邻等级难分则注明边界或留空。

### 自述体验强度 reported_experience_intensity

仅在主体明确报告自身体验程度时编码，0—5 沿用轻微、明确、强化、显著、极端的程度约定；没有报告程度则填 null，不从文风反推。0 仅用于主体明确否认目标情绪，例如“完全不难过”，保留否定命题。

引用自述归到被引用者。小说人物自述标虚构身份；叙述者推测、分析者推断和身体描写不能填入此字段。主体自报“8/10”时原样保留，不擅自转换为 0—5；项目预先规定转换办法时注明办法。

### 时间与基线

按同一主体和相同或明确变化的对象串联情绪。以输入时间标记区分当下、过去和假设，不把叙述顺序自动当作事件顺序。没有个人基线或多个时间点就不报告长期趋势。

## 其他核对

- 身体反应可能来自体力、疾病、环境或情绪，保留解释范围。
- 工作礼貌可能体现角色规范，没有关系证据就不推断亲疏。
- 景物可提供氛围线索，人物情绪仍需人物或叙述证据。
- 新闻立场、广告诉求、公文语体不等于作者体验或受众实际感受。
- 未知、未表达、明确否认分别记录，不统一编码为中性。
